# User Stories

This file contains the user stories covered by the current PerthPins application.

1. As a visitor, I want to see an interactive map on the homepage that displays all check-in locations, so that I can quickly get a visual overview of where people have been around Perth and UWA.
2. As a visitor, I want to browse recent check-ins on the homepage, so that I can quickly see new places shared by the community.
3. As a visitor, I want to browse all check-ins on an Explore page and filter them by category, minimum rating, and sort order, so that I can find posts relevant to what I am looking for.
4. As a visitor, I want to search for check-ins by keyword, so that I can quickly find posts about a specific place or topic without scrolling through the full list.
5. As a visitor, I want to click on a check-in card to open its full detail page, so that I can read the complete description, view photos, see the exact location on a map, and read comments.
6. As a new user, I want to register an account with a username, email, and password, so that my check-ins and saved places are tied to my own profile.
7. As a registered user, I want to log in and log out, so that I can safely access account-only features.
8. As a logged-in user, I want to create a check-in with a place name, map pin, photos, title, category, rating, and description, so that I can share a location I visited with the community.
9. As a user creating a check-in, I want to click a "Pick on Map" button to open a small interactive map and drop a pin on the exact spot, so that my check-in is pinned to the correct coordinates.
10. As a logged-in user, I want to save and unsave check-ins, so that I can keep a personal list of places I want to visit later.
11. As a logged-in user, I want to leave a comment on a check-in, so that I can share my own experience of that place or ask the author a question.
12. As a logged-in user, I want to view and edit my profile, so that I can update my avatar, username, and bio and manage my own check-ins and saved places.
13. As a logged-in user, I want to delete my own check-ins, so that I can remove posts I no longer want to share.
